设置与同步
把同目录下 api.php 一起上传到你的 PHP 主机（Hostinger 等）即可，数据存在你自己的服务器，无需注册任何账号。
接口地址填完整 URL，例如 https://comsourcing.com/habit/api.php
步骤：supabase.com 注册 → New project → 左侧 SQL Editor → 粘贴上面复制的 SQL → Run
→ Project URL：左侧菜单 Data API 页面里复制。
→ Key：Settings → API Keys → 点 Legacy anon, service_role API keys 标签，复制 anon public；新版 sb_publishable_ 开头的 key 也能用。
同步码建议用一串随机字符，别人猜不到就看不到你的数据。
jsonbin.io 免费注册，新建一个 Bin 后把 ID 和 Master Key 填进来。注意免费版有请求次数限制。
